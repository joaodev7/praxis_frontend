# PRAXIS — Portal Web da Empresa de Nutrição

Portal administrativo e de gestão operacional de responsabilidade técnica em nutrição.

## Tecnologias
- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **Axios** + **React Router v6**

## Instalação e Execução

```bash
cd frontend
npm install
npm run dev
```

O portal estará disponível em `http://localhost:5173`.
